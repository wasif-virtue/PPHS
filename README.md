# Paragon Public High School Website

A static, multi-page website for Paragon Public High School in Adda Gamber, Okara. The site presents school information, academics, admissions, news, and contact details using HTML, CSS, and vanilla JavaScript.

## Pages and content

- Home page with school introduction and facilities
- About, academics, admissions, news, and contact pages
- Navigation between pages and in-page sections
- Responsive mobile navigation
- Local images and school branding
- Dynamic copyright year

## Run locally

No package installation or build step is required. Clone the repository and open `index.html` in a modern browser.

```bash
git clone https://github.com/wasif-virtue/PPHS.git
cd PPHS
```

## Project structure

| File or folder | Purpose |
| --- | --- |
| `index.html` | School home page |
| `about.html` | School overview |
| `course.html` | Academics information |
| `admissions.html` | Admissions information |
| `blog.html` | News and updates |
| `contact.html` | Contact and directions |
| `style.css` | Shared visual design and responsive layout |
| `script.js` | Mobile menu and current-year behavior |
| Image files | School and page imagery |

Contact details and school information are reproduced from the website source; verify them with the school before using them operationally.
